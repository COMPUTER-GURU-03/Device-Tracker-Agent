This repository is named **Device Tracker Agent**. Its current contents are still minimal, so this page deliberately describes the project as an early-stage starting point rather than claiming a working tracking system.

## Project direction

The name suggests a software agent associated with device tracking. Before implementation expands, the project should clearly define:

- **Purpose:** what devices are tracked and who uses the system.
- **Tracking method:** what data is collected, from which authorized source, and how frequently.
- **Privacy and consent:** how users are informed, how access is controlled, and how sensitive data is protected.
- **Reliability:** how offline devices, stale updates, and missing location or status data are handled.

## Current status

- Repository created; implementation and supported features are not yet documented.
- Technology stack, setup instructions, and tests should be added as the implementation takes shape.
- Do not treat this repository as a production-ready tracking tool.

## Development checklist
